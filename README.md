# Smart College Complaint and Issue Tracking System

## Overview

The **Smart College Complaint and Issue Tracking System** is a Java console-based application developed to manage student records and simplify complaint management within a college. The project is built to practice Core Java concepts such as arrays, loops, conditional statements, methods, and menu-driven programming.

## Features

* Create Student
* Delete Student
* Display Students
* Search Student
* Update Student
* Menu-Driven Console Application
* Array-Based Data Storage

## Technologies Used

* Java
* VS Code / Eclipse
* Arrays
* Scanner Class

## How to Run

1. Clone the repository.
2. Open the project in VS Code or Eclipse.
3. Compile the program:

   ```
   javac Main.java
   ```
4. Run the program:

   ```
   java Main
   ```
